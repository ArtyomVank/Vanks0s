# Путь до Vanks OS 1.0

Vanks Shell станет оболочкой Vanks OS в 1.0, когда на ней можно жить каждый
день так же, как на Delta + Hyprland. До тех пор — только локально.

## 0.1 — фундамент ✓

- [x] протокол Wayland, xdg-shell, shm, буфер обмена, xdg-output
- [x] окна по центру каскадом; щелчок поднимает окно и даёт фокус
- [x] перемещение и размер: просьбы программ и Super+перетаскивание
- [x] сочетания: терминал, закрыть окно, выход (в любой раскладке)
- [x] окно отладки (winit)

## 0.2 — настоящая сессия ✓ (в коде; на железе — docs/TESTING.md)

- [x] бэкенд udev: DRM/KMS, несколько мониторов, горячее подключение
- [x] libinput: клавиатуры, мыши, тачпады (тап, прокрутка, скорость — из Delta)
- [x] libseat / logind: переключение консолей Ctrl+Alt+F1…F12, пауза и возврат
- [x] свой курсор (тема xcursor, анимированные, cursor-shape-v1, картинки программ)
- [x] раскладки xkb и переключение — из «Клавиатуры» Delta (`input` в settings.json)
- [x] linux-dmabuf: программы отдают кадры из видеопамяти
- [x] запуск как сессия: `data/vanks-shell.desktop`, `tools/install-session.sh`
- [x] `--probe`: видеокарты, мониторы (EDID), доступ — без захвата
- [x] штатный выход по SIGTERM/SIGINT, аварийный — Ctrl+Alt+Backspace
- [ ] **проверка на железе** (NVIDIA + HDMI-A-1 у разработчика)
- [ ] вторая видеокарта (ноутбуки iGPU + дискретная)
- [ ] жесты тачпада (смахивания — рабочие столы, щипок)
- [ ] перерисовка по требованию (сейчас без изменений — проверка раз в кадр)

## 0.3 — Delta поверх Vanks Shell

- [ ] wlr-layer-shell: доки, виджеты, уведомления Delta (Quickshell) встают как есть
- [ ] ext-session-lock: экран блокировки Delta
- [ ] xdg-decoration (рамки окон от оболочки), xdg-activation, fractional-scale, viewporter
- [ ] foreign-toplevel: список окон для дока
- [ ] IPC Vanks Shell вместо `hyprctl` (окна, рабочие столы, мониторы, события) и слой совместимости в Delta
- [ ] screencopy / порталы: снимки экрана, запись, демонстрация экрана

## 0.4 — окна как в Delta

- [ ] рабочие столы (5 по умолчанию, как в доке Delta)
- [ ] прилипание к краям: половина, четверть, весь экран — с подсветкой
- [ ] развернуть, свернуть, полноэкранный режим
- [ ] XWayland: старые программы и игры (Steam, Wine)
- [ ] правила окон (плавающие, размеры, рабочий стол)

## 0.5 — свой вид

- [ ] анимации окон (открытие, закрытие, перемещение) на пружинах
- [ ] «желе» при перетаскивании — в самом композиторе (сейчас — в Delta)
- [ ] размытие под окнами и панелями (стекло Delta), скругления, тени
- [ ] обои и видеообои в композиторе
- [ ] прямой вывод полноэкранных игр (direct scanout), VRR, tearing-control

## 0.6 — экран и цвет

- [ ] расстановка и режимы мониторов из «Экрана» Delta (`monitors`, `display`)
- [ ] масштаб и дробный масштаб по мониторам
- [ ] HDR и цветовое управление, ночной свет
- [ ] поворот, зеркалирование, частота обновления

## 0.9 — готовность

- [ ] настройки из `~/.config/delta/settings.json` (те же, что в «Настройках» Delta)
- [ ] стабильность: неделя без падений на компьютере разработчика
- [ ] пакет `vanks-shell` и выбор оболочки на экране входа
- [ ] образ Vanks OS с Vanks Shell по умолчанию

## 1.0

- [ ] Vanks Shell — оболочка Vanks OS по умолчанию; Delta работает поверх неё
