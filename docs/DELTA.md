# Delta — графическое окружение Vanks OS

Статус (2026-10-28): фазы 0–3 готовы (ISO в фазе 3 ещё не собирался). Оболочка собрана целиком: доки с
меню, уведомления, OSD, окно приложений, выбор обоев и видеообои, виджеты с
редактором, экран блокировки, меню питания, экран входа (greetd), приложение
«Настройки» со всеми разделами; сворачивание окон в значок дока («джинн»),
оформление программ GTK/Qt, агент polkit, автовход. Проверено во вложенном Hyprland. Версии
проверены на 2026-10-27: Hyprland 0.56.2, Quickshell 0.3.2, Lua 5.5 внутри
Hyprland.
Не проверено на реальном железе: HDR, VRR, DDC, ночной свет, Wi-Fi, Bluetooth,
батарея, ввод мышью, несколько мониторов, настоящий greetd. Список того, что
осталось, — в разделе 8.
Как запускать и проверять — [delta/README.md](../delta/README.md).
Визуальный эталон — концепт-макет (доки-капли, сетка виджетов, экран блокировки,
настройки): https://claude.ai/artifact/95e28BYJtmu6GcoJ296Azj

## 1. Решение: Delta = своё окружение поверх композитора Hyprland

Пользователь видит Delta как отдельное окружение: свой пункт сессии, свой экран
входа, своя оболочка, свои настройки, свой конфиг. Hyprland работает внутри как
«движок» — его конфиг генерирует Delta, руками его никто не трогает.

Почему не свой композитор с нуля:

| Что нужно | Hyprland 0.56 | Свой композитор |
|---|---|---|
| HDR, 10 бит, ICC, авто-HDR в играх | есть (`cm = hdr`, `sdrbrightness`, `cm_auto_hdr`) | COSMIC за ~3 года и niri за ~3 года HDR так и не сделали |
| VRR, дробное масштабирование, поворот, зеркалирование | есть, меняется на лету | годы работы |
| Блокировка, layer-shell, скриншоты, запись экрана, порталы | всё реализовано | писать каждый протокол |
| NVIDIA, XWayland, планшеты, жесты | работает | отдельные большие задачи |
| Анимации окон | `popin`/`slide`/`gnomed`, bezier и spring-кривые | писать самим |

Чего в Hyprland нет и как закрываем:

- **Сворачивания нет.** Делаем в оболочке: снимок окна через screencopy →
  окно мгновенно уходит в `special:minimized` → снимок анимированно «втягивается»
  в значок дока. Разворачивание — обратная анимация. Плагин не нужен.
- **«Желе» при перетаскивании.** Только плагин на C++. Поддерживаемого плагина
  нет, ABI ломается на каждой версии. Поэтому это фаза 4: свой плагин
  `delta-hypr`, а версию Hyprland мы фиксируем в собственном репозитории
  (метапакет `delta` тянет ровно ту версию, с которой собран плагин).
- **Конфиг переезжает на Lua** (с 0.55, hyprlang уберут в ближайших версиях).
  Сразу пишем только `hyprland.lua`. Точный синтаксис сверяем с примером из
  установленного пакета, а не по памяти.

## 2. Стек

| Слой | Чем делаем | Почему |
|---|---|---|
| Композитор | Hyprland (зафиксированная версия) | см. выше |
| Оболочка, блокировка, экран входа, настройки | **Quickshell 0.3.x** (QML/Qt 6), в официальном репозитории Arch | layer-shell, ext-session-lock, greetd, PAM, уведомления, MPRIS, PipeWire, UPower, Bluetooth, NetworkManager, трей, screencopy, idle, polkit-агент — всё встроено; QML даёт плавные GPU-анимации морфинга |
| Видеообои | `mpvpaper -o "hwdec=auto"` отдельным процессом, пауза при полноэкранном окне | не нагружает процесс оболочки |
| Экран входа | `greetd` + минимальный Hyprland + Delta-greeter на Quickshell | выглядит как экран блокировки, вход по-виндовому |
| Ночной свет, гамма | `hyprsunset` | не попадает в скриншоты |
| Яркость | logind `SetBrightness` (ноутбук), `ddcutil` + `i2c-dev` (внешние мониторы) | без root |
| Тема приложений | `adw-gtk3` + переменные GTK4, `qt6ct`/Kvantum, свои цвета из акцента | приложения выглядят в стиле системы |

фиксируем и обновляем осознанно.

              osd/      громкость, яркость, раскладка — шарик из дока

              widgets/  сетка виджетов рабочего стола, редактор, все виджеты
              lock/     экран блокировки (общий код с greeter)
              minimize/ анимация сворачивания в значок
  settings/   приложение «Настройки» (отдельный процесс Quickshell)
  greeter/    экран входа
  helpers/    delta-sysinfo, delta-gpu, delta-monitors, delta-apply (bash)

**Хранение настроек.** Один источник правды — `~/.config/delta/settings.json`.
Настройки пишут в него, оболочка следит за файлом и применяет изменения сразу.
Всё, что касается Hyprland, `delta-apply` переводит в
`~/.config/delta/hypr/*.lua`, а `hyprland.lua` их подключает.

**Привилегированные действия** (имя компьютера, часовой пояс, аватар в
AccountsService) — только через системные D-Bus-службы и polkit, без sudo.

## 4. Все тонкости, которые должны работать

### Экран (каждый монитор отдельно)
- Разрешение и частота: список режимов из EDID, плюс `preferred`/`highrr`.
- Масштаб: 100–300 % с шагом, который Hyprland принимает без округления;
  предпросмотр итогового «как будто» разрешения.
- Поворот (0/90/180/270 и отражения), расположение мониторов перетаскиванием,
  основной монитор (на нём доки), зеркалирование, отключение.
- VRR: выкл / вкл / только в полноэкранном / только для игр и видео.
- HDR: переключатель (`cm = hdr`, `bitdepth = 10`), яркость SDR-контента в HDR
  (`sdrbrightness`), насыщенность, авто-HDR для полноэкранных игр,
  ICC-профиль. Пункт HDR показывается только если монитор его поддерживает.
  Предупреждения: HDR экспериментальный; 10 бит ломают часть программ записи
  экрана.
- **Защита от чёрного экрана:** новые параметры применяются на лету, затем
  15 секунд окно «Оставить?»; без ответа — откат. В файл пишем только после
  подтверждения.
- Яркость: встроенный экран через logind, внешние через DDC/CI (если монитор
  умеет), общий ползунок в меню и OSD.
- Ночной свет: температура, расписание (закат/рассвет или по времени).
- Горячее подключение монитора: восстановить сохранённый профиль для этого
  набора мониторов (по описанию EDID, а не по имени порта).

### Профиль и учётные записи
- Имя (отображаемое), аватар: выбор файла, обрезка по кругу, стандартные
  аватары; запись в AccountsService и `~/.face`. Аватар и имя видны на экране
  входа, блокировки и в меню питания.
- Смена пароля (через `passwd` в PTY с понятными ошибками).
- Вход без пароля / автовход, блокировка при пробуждении, время до блокировки.
- Другие пользователи: список, добавить/удалить (polkit, только администратор).

### О системе
- Vanks OS + версия Delta, ядро, время работы, процессор, видеокарта(ы),
  память, диски (занято/свободно), разрешение экранов.
- Переименование компьютера (hostnamed), копирование сведений одной кнопкой.

### Остальные разделы Настроек
- Оформление: тёмная/светлая, 12+ тем, любой акцент, прозрачность стекла,
  скругления, шрифт; применяется и к GTK/Qt-приложениям, курсору, значкам.
- Доки: края, длина (полный/плиточный/компактный), автоскрытие, модули верха.
- Окна: анимации открытия/закрытия/сворачивания, «желе» (когда будет плагин),
  отступы, рамки.
- Виджеты, экран блокировки, обои (папка, видео, смена по таймеру).
- Звук: выходы/входы, громкость приложений, звуки системы.
- Сеть, Bluetooth (сопряжение с PIN пока не поддерживается в Quickshell —
  нужен свой агент BlueZ).
- Питание: профили (power-profiles-daemon), сон, гибернация (если есть swap),
  действие при закрытии крышки, процент заряда.
- Клавиатура: раскладки, сочетание переключения, повтор; все горячие клавиши
  Delta с переназначением.
- Мышь и тачпад: скорость, естественная прокрутка, тап, жесты.
- Дата и время, язык и регион, приложения по умолчанию, автозапуск.
- Уведомления: по приложениям, «не беспокоить», на экране блокировки.
- Обновления: `checkupdates`, список, установка через polkit, перезагрузка.
- GitHub — заголовок на будущее.

### Системная обвязка (без неё «идеально» не будет)
- polkit-агент в стиле Delta, gnome-keyring разблокируется паролем входа
  (`pam_gnome_keyring` в `/etc/pam.d/greetd`).
- Порталы: `xdg-desktop-portal-hyprland` + `-gtk` для выбора файлов.
- Скриншоты и запись экрана, история буфера обмена, XWayland, шрифты, эмодзи.
- Сон/выход из сна: блокировка до сна, восстановление мониторов после.
- Полноэкранные игры: доки и уведомления не мешают, видеообои на паузе.

## 5. Экран входа = экран блокировки

- `greetd` запускает Hyprland с конфигом только для greeter'а и Delta-greeter.
- Greeter выглядит как экран блокировки: те же обои, часы, виджеты, аватар.
  Обои и тема пользователя копируются в `/var/lib/delta-greeter/`.
- После ввода пароля: анимация разблокировки → `launch` сессии → первый кадр
  сессии — те же обои, оболочка доигрывает появление доков.
- Опция «Входить без пароля»: автовход + сразу экран блокировки. Минус —
  связка ключей не разблокируется сама; в настройках предупреждаем об этом.

## 6. Установщик: live-сессия на Delta, а не на GNOME

Решение: **live-образ загружается в Delta**, Calamares открывается окном поверх.

- Человек сразу видит систему, которую ставит, и проверяет её на своём железе.
- В образе один графический стек вместо GNOME + GDM — ISO меньше, быстрее
  грузится в RAM (`copytoram=y`).
- Риск: Hyprland нужна 3D-видеокарта. В VirtualBox и QEMU без virgl он может не
  стартовать. Поэтому в меню загрузки два пункта:
  1. **Vanks OS (Delta)** — по умолчанию;
  2. **Безопасный режим** — `nomodeset` + Calamares в `cage` с программной
     отрисовкой (`WLR_RENDERER=pixman`). Работает на любом железе.
  Если Hyprland не стартовал, live-служба автоматически переходит во второй
  вариант.
- Calamares запускается через `sudo -n env …` (правило sudoers только для live-
  пользователя) с `QT_QPA_PLATFORM=wayland`, окно плавающее по центру.
  `pkexec` на Wayland теряет переменные окружения — не используем.
- Выбор в установщике: **Delta** (по умолчанию) и GNOME как запасной вариант.
  Старый вариант «Hyprland + Waybar» заменяется Delta.

## 8. Что осталось после фазы 1

- **Проверить на настоящем экране:**
  - вход в сессию Delta;
  - мышь: наведение, перетаскивание, меню;
  - плавное проявление стола при блокировке (`session_lock_xray`; на снимках grim под блокировкой чёрный фон);
  - яркость DDC, HDR, VRR, ночной свет (hyprsunset).
- **Фаза 2 — сделано:**
  - **Сворачивание (`minimize/`):**
    - свёрнутое окно живёт на скрытом рабочем столе `special:minimized`;
    - анимация «джинн» — шейдер `minimize/shaders/genie.*`: снимок окна берётся, пока окно видно, и хранится до разворачивания;
    - работают Super+M, нажатие на единственное активное окно в доке, кнопка «свернуть» в заголовке программы (событие `minimized`);
    - нажатие на значок в доке разворачивает окно на текущий стол;
    - `windows.genie: false` — сворачивание без анимации.
  - **Оформление GTK/Qt (`appearance/ThemeSync.qml`):** оболочка запускает `theme-apply` при первом входе и после любой смены темы; что уже применено, помнит отметка в state-папке.
  - **Агент polkit (`polkit/`):** окно «Нужно подтверждение» с паролем. Во вложенной сессии не регистрируется; проверка — `delta-shell ipc call polkit demo`.
  - **Автовход:**
    - `delta-autologin` (через `pkexec`, право `org.vankos.delta.autologin`) пишет свой блок `[initial_session]` в `/etc/greetd/config.toml`;
    - переключатель — «Настройки» → «Профиль».
- **Осталось от фазы 2:**
  - свёрнутое окно, которое программа активирует сама (например, щелчок по уведомлению), не разворачивается: Hyprland не присылает события;
  - нет снимка после перезапуска оболочки — тогда окно разворачивается без анимации;
  - связка ключей при автовходе не разблокируется (так устроен gnome-keyring).
- **В `common/ui`:** однострочное поле ввода нужно всем, и сейчас у каждого модуля свой `Field`. Туда же — Dropdown/Select, Dialog, Picker, Avatar, BigClock, плеер.
- **Фаза 3 (ISO) — сделано:**
  - **Live-сессия:** greetd вместо GDM; `vankos-live-setup` при загрузке кладёт `/etc/greetd/config.toml` (из `/usr/share/vankos/greetd-live.toml`) с автовходом `vanks`.
  - **`vankos-live-session`:**
    - обычный режим — Delta;
    - `vankos.safe=1` или Delta упала быстрее чем за 30 с — Calamares в `cage` (pixman, `QT_QUICK_BACKEND=software`);
    - экран входа после выхода из сессии: Delta-greeter, а в безопасном режиме — `agreety`.
  - **Меню загрузки:** третий пункт «Safe mode» (`nomodeset vankos.safe=1`, в BIOS ещё `vga=791`); у syslinux теперь видимое меню (`menu.c32`).
  - **Установщик:**
    - Calamares — Wayland-клиент (`wayland;xcb`, абсолютный `WAYLAND_DISPLAY`, стиль Fusion);
    - автозапуск через `dex`, установщик первым в доке; в live нет автоблокировки и сна.
  - **Выбор стола:** Delta (по умолчанию, `iso/lists/delta.txt`) и GNOME. Вариант «Hyprland + Waybar» убран вместе с конфигами и картинкой.
  - **`desktop.sh` для Delta:**
    - ставит `config.toml` и PAM greetd из пакета delta;
    - `systemd-tmpfiles --create` для каталогов экрана входа;
    - включает `greetd.service`.
  - **Сборка:**
    - `tools/build-delta.sh` собирает пакет при каждой сборке в `[vankos-pkgs]`, он же попадает в офлайн-репозиторий;
    - для slim-ISO копия пакета лежит в `/usr/share/vankos/pkgs`, `desktop.sh` ставит её через `pacman -U`;
    - после `mkarchiso` `build.sh` проверяет, что в образе есть Delta, greetd и cage.
- **Осталось от фазы 3:**
  - собрать ISO (`sudo ./build.sh`) и проверить в QEMU с virgl, без virgl (автопереход в безопасный режим) и на железе;
  - установленная система не получает обновлений delta: пакета нет в репозиториях, нужен свой репозиторий Vanks OS;
  - если Delta не запускается на видеокарте установленной системы, экран входа greetd (тоже Hyprland) не появится — тогда выбирать GNOME;
  - автовход из экрана «Пользователи» Calamares пока не переносится в greetd (включается потом в «Настройках»).
