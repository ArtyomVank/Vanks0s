# Путь до Vanks OS 1.0

композитор Delta станет основой Vanks OS в 1.0, когда на ней можно жить каждый
день так же, как на Delta + Hyprland. До тех пор — только локально.

## 0.1 — фундамент ✓

- [x] протокол Wayland, xdg-shell, shm, буфер обмена, xdg-output
- [x] окна по центру каскадом; щелчок поднимает окно и даёт фокус
- [x] перемещение и размер: просьбы программ и Super+перетаскивание
- [x] сочетания: терминал, закрыть окно, выход (в любой раскладке)
- [x] окно отладки (winit)

## 0.2 — настоящая сессия ✓ (в коде; на железе — docs/TESTING.md)

- [x] бэкенд udev: DRM/KMS, несколько мониторов, горячее подключение
- [x] libinput: клавиатуры, мыши, тачпады (тап, прокрутка, скорость — из Delta)
- [x] libseat / logind: переключение консолей Ctrl+Alt+F1…F12, пауза и возврат
- [x] свой курсор (тема xcursor, анимированные, cursor-shape-v1, картинки программ)
- [x] раскладки xkb и переключение — из «Клавиатуры» Delta (`input` в settings.json)
- [x] linux-dmabuf: программы отдают кадры из видеопамяти
- [x] запуск как сессия: `data/delta-compositor.desktop`, `tools/install-session.sh`
- [x] `--probe`: видеокарты, мониторы (EDID), доступ — без захвата
- [x] штатный выход по SIGTERM/SIGINT, аварийный — Ctrl+Alt+Backspace
- [ ] **проверка на железе** (NVIDIA + HDMI-A-1 у разработчика)
- [ ] вторая видеокарта (ноутбуки iGPU + дискретная)
- [x] смахивание тремя пальцами — рабочие столы; жесты передаются программам
- [ ] щипок как жест самой оболочки
- [ ] перерисовка по требованию (сейчас без изменений — проверка раз в кадр)

## 0.3 — Delta поверх композитора Delta ✓ (в окне отладки; на железе — docs/TESTING.md)

Сама Delta не менялась: композитор Delta отвечает ей как Hyprland (меньше прослоек
и никаких правок в публичном репозитории).

- [x] IPC как у Hyprland: сокеты, `j/…`, события, `dispatch` с Lua-командами `hl.dsp.*`, `hyprctl`
- [x] wlr-layer-shell: доки, виджеты, уведомления Delta встают как есть
- [x] рабочие столы, свёрнутые (`special:minimized`), развернуть, полный экран
- [x] глобальные сочетания (hyprland_global_shortcuts), Super сам по себе — меню
- [x] ext-session-lock: экран блокировки Delta; замок упал — экран закрыт, Delta берёт его снова
- [x] foreign-toplevel и toplevel-mapping: список окон для дока
- [x] focus-grab: щелчок мимо закрывает меню
- [x] ext-idle-notify и idle-inhibit: простой
- [x] xdg-decoration: кнопки окон у Delta, без заголовков программ
- [x] автозапуск Delta (`delta-shell`, помощник первого запуска)
- [ ] **проверка на железе** и щелчков мимо меню (в окне отладки проверялось через IPC, без мыши)
- [ ] плавный переход при разблокировке (`misc.session_lock_xray` в Hyprland)
- [x] `hl.dsp.window.move`, `resize`, `pin`, `alter_zorder`, `set_prop` (прозрачность 0 — окно под живой копией)
- [ ] `set_prop` для размытия и теней (вместе с эффектами в 0.5), `dpms` (пока принимается и ничего не делает)
- [x] xdg-activation, fractional-scale, viewporter, single-pixel-buffer, content-type
- [x] pointer-constraints и relative-pointer (мышь в играх), wp-presentation, primary selection, wlr-data-control
- [x] wlr-screencopy (grim, wf-recorder) и hyprland_toplevel_export: «желе» и сворачивание Delta
- [ ] портал: демонстрация экрана через xdg-desktop-portal (не проверялась)
