# композитор Delta

Своя графическая оболочка Vanks OS на Wayland — композитор уровня GNOME или
Hyprland, на Rust и [Smithay](https://github.com/Smithay/smithay). Когда она
станет полноценной, выйдет **Vanks OS 1.0**; до тех пор Vanks OS работает на
Delta (Hyprland + Quickshell).

> **Не публикуется.** Репозиторий только локальный (без `git remote`), пока
> оболочка не готова к 1.0. Не добавляйте его в публичный репозиторий Vanks0s.

## Что уже умеет (0.4)

**Delta поверх композитор Delta** (0.3): рабочий стол Vanks OS работает здесь без
единой правки в самой Delta. композитор Delta отвечает ей как Hyprland 0.57 с
конфигом на Lua, поэтому на Quickshell всё встаёт как есть: панели и док,
обои, меню приложений, виджеты, уведомления, экран блокировки, простой, столы,
кнопки окон, сочетания (Super, Super+S, Super+L, громкость…). Что пока не
работает (размытие и анимации окон, правила окон, зеркалирование) — в
[docs/ROADMAP.md](docs/ROADMAP.md).

**Окна и экран** (0.4): XWayland для старых программ и игр; прилипание к краям с
подсветкой Delta; «желе» и живая копия окна; снимки и запись экрана (grim,
wf-recorder); захват мыши для игр; смахивание тремя пальцами; мониторы, масштаб и
поворот из настроек Delta. В настоящей сессии это пока не проверялось — смотрите
[docs/TESTING.md](docs/TESTING.md).

**Настоящая сессия** (0.2): с текстовой консоли или экрана входа композитор Delta
сама ведёт видеокарту (DRM/KMS) и ввод (libinput) через libseat — как Hyprland:
все мониторы основной видеокарты с горячим подключением, свой курсор из темы
(и фигуры по просьбе программ — cursor-shape-v1), dmabuf, раскладки, повтор
клавиш, тачпад и скорость мыши — из настроек Delta, Ctrl+Alt+F1…F12 —
другие консоли. Внутри Hyprland по-прежнему открывается окном отладки.

**Фундамент** (0.1):

- протокол Wayland: поверхности, общая память (shm), xdg-shell (окна и меню),
  буфер обмена и перетаскивание между программами, xdg-output;
- окна: новое — по центру экрана каскадом, впереди всех и с фокусом;
  щелчок по окну поднимает его и отдаёт ему клавиатуру; закрыли окно —
  фокус тому, что под ним;
- перемещение и изменение размера: за заголовок и края (по просьбе
  программы), **Super + левая кнопка** — за любое место окна, **Super + правая**
  — размер за ближайший угол;
- сочетания (работают и в русской раскладке):
  - **Super+Enter** — терминал (`DELTA_TERMINAL`, по умолчанию kitty)
  - **Super+Q** — закрыть окно
  - **Super+Shift+E** — выйти
  - **Ctrl+Alt+Backspace** — аварийный выход
  - **Ctrl+Alt+F1…F12** — другая консоль (в настоящей сессии)
- запуск в окне внутри текущей сессии (бэкенд winit) — для разработки.

## Сборка и запуск

```bash
cargo build
tools/run-nested.sh            # окно отладки, внутри — терминал
tools/run-nested.sh -c foot    # внутри — другая программа
tools/run-delta.sh             # внутри — Delta из исходников рядом (../vankos)
```

Журнал подробнее: `RUST_LOG=debug tools/run-nested.sh`.

```bash
target/debug/delta-compositor --probe   # видеокарты, мониторы, раскладки — ничего не захватывая
```

Настоящая сессия с консоли и с экрана входа, как оттуда выйти —
[docs/TESTING.md](docs/TESTING.md).
